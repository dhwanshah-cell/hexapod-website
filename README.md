# Hexapod

Project website for **Hexapod**, a six-legged search-and-rescue robot that goes into collapsed buildings before
rescuers do, looks and listens for survivors, and alerts the team outside.

Smart India Hackathon 2026 · PS SIH26218 · Student Innovation: Robotics and Drones · Team Scammers

**Live site:** https://dhwanshah-cell.github.io/hexapod-website/

## What is here

- `index.html`: the whole site (one page, no build step)
- `assets/seq/`: the scroll sequence (3D renders of the robot's model, and the LiDAR-style frames)
- `assets/photos/`, `assets/video/`, `assets/sim/`: photos of the real build, the field-test clip and renders

## Run it locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
